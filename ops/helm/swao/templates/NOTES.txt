SWAO assessment job deployed.

  Release:   {{ .Release.Name }}
  Namespace: {{ .Release.Namespace }}
  App ID:    {{ .Values.app.id }}
  Image:     {{ .Values.image.repository }}:{{ .Values.image.tag }}
  Workspace: PVC {{ .Values.app.workspacePvcName }} mounted at /workspace

The Job runs once and exits. Monitor progress with:

  kubectl logs -l app.kubernetes.io/instance={{ .Release.Name }} -f

The workspace PVC ({{ .Values.app.workspacePvcName }}) must exist in the same
namespace before deploying. It should be pre-populated with:

  <workspace>/apps/{{ .Values.app.id }}/source/    -- application source code
  <workspace>/.swao.yml                            -- workspace configuration

Assessment output (wsp.yaml, reports/, artifacts/) is written back to the PVC.

To pass credentials, use:

  helm upgrade {{ .Release.Name }} ./ops/helm/swao \
    --set app.id={{ .Values.app.id }} \
    --set credentials.SWAO_CREDENTIAL_ANTHROPIC_API_KEY=sk-ant-...
