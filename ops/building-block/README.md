# SWAO meshStack Building Block

This directory contains the meshStack Building Block Definition for SWAO.
It allows SWAO assessments to be ordered self-service from the meshStack
Developer Portal catalog.

## Files

| File | Purpose |
|---|---|
| `manifest.yaml` | Building Block Definition (kind: BuildingBlockDefinition) |
| `swao-bb-<version>.tar.gz` | Upload package for meshStack catalog (generated by `package-bb.sh`) |

## Prerequisites

- Docker image `accenture/swao:dev` built and pushed to a registry accessible
  from your meshStack instance (see `scripts/build-image.sh`)
- meshStack instance with Developer Portal catalog enabled
- UniPipe service broker configured in the meshStack instance (M12/M14 scope)

## Building the package

From the repository root:

```bash
bash scripts/package-bb.sh
```

This produces `ops/building-block/swao-bb-<version>.tar.gz`.

## Uploading to meshStack

1. Log in to the meshStack Administrator area.
2. Navigate to **Developer Portal > Building Blocks > Definitions**.
3. Click **Import** and upload `swao-bb-<version>.tar.gz`.
4. Review the imported definition: inputs, outputs, executor endpoint.
5. Publish the definition to make it visible in the catalog.

## Local validation (no live meshStack required)

Validate the manifest YAML is well-formed:

```bash
node -e "
const yaml = require('js-yaml');
const fs   = require('fs');
const doc  = yaml.load(fs.readFileSync('ops/building-block/manifest.yaml', 'utf8'));
console.log('kind:', doc.kind);
console.log('inputs:', doc.spec.inputs.map(i => i.name));
console.log('outputs:', doc.spec.outputs.map(o => o.name));
console.log('OK');
"
```

## Input reference

| Input | Type | Required | Default | Description |
|---|---|---|---|---|
| `app_id` | string | yes | -- | Application directory name inside the workspace |
| `workspace_path` | string | yes | `/workspace` | Absolute path to portfolio workspace |
| `llm_provider` | string | no | `stub` | `anthropic`, `ollama`, or `stub` |
| `anthropic_api_key` | secret | no | -- | Required when `llm_provider` is `anthropic` |

## Output reference

| Output | Type | Description |
|---|---|---|
| `wsp_url` | string | Link to generated WSP YAML artefact |
| `seven_r_label` | string | 7R migration recommendation |
| `coverage_score` | number | Assessment completeness 0-100 % |
