# STACKIT (stackit)

This page describes the Landing Zone catalogue `stackit` as shipped with SWAO: the provider and its sovereignty model, the regions with their residency and certifications, how the catalogue is refreshed and how to use it as a target.

## Provider and sovereignty model

STACKIT is the cloud of the Schwarz Group, operated by STACKIT GmbH & Co. KG in Germany. The catalogue covers the regions `eu01` (Germany) and `eu02` (Austria) and is generated from the STACKIT PIM API.

Sovereignty model: the operator is an EU entity and no extraterritorial exposure is recorded. `eu01` records BSI C5 and ISO/IEC 27001, `eu02` records ISO/IEC 27001. STACKIT is also the sovereign profile that the landing zone readiness checks of [Pass 23 (LZR)](/passes/23-lzr) currently evaluate.

## Using this catalogue

Name a region of this catalogue as a target of the [Landing Zone Catalog Assessment](/assessment/landing-zone), on the command line or in the app `.swao.yml`:

```bash
swao lz catalogue show stackit
swao assess --type landing-zone-catalog --app <app-id> --lz-cat-targets "stackit:eu01"
```

```yaml
assessment:
  landing_zone:
    targets:
      - stackit:eu01
```

A geography such as `stackit:Europe` instead of a region ID resolves to the default region shown in the summary.

To correct or extend the facts for one engagement, copy the catalogue into the workspace with `swao lz catalogue copy stackit` and edit `wsp/inputs/catalogs/lz-catalogues/stackit/index.json`; the workspace copy then takes precedence. See [Adapting LZ catalogues](/runbooks/adapting-lz-catalogues).

Catalogue facts are point-in-time and are not legal advice. Check the date and confidence above and review the provider's contracts before you rely on a verdict.
