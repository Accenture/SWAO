# AWS ISOE Europe (classified) (aws-iso-e)

This page describes the Landing Zone catalogue `aws-iso-e` as shipped with SWAO: the provider and its sovereignty model, the regions with their residency and certifications, how the catalogue is refreshed and how to use it as a target.

## Provider and sovereignty model

AWS ISOE Europe is an AWS partition for classified and sector-specific European workloads, with the region `eu-isoe-west-1`. Its service list is generated from the AWS SDK endpoint data like the other AWS catalogues.

Sovereignty model: public information about the operator and the certifications of this partition is sparse, so the catalogue records conservative facts: a US-entity operator with US CLOUD Act and FISA Section 702 exposure, EU-wide residency and no certifications. The confidence is low. Treat the sovereignty facts as unverified and confirm them with the provider before you report a result.

The catalogue records no certifications for any region. A framework that requires a certification (for example BSI C5) therefore reports a certification gap for every region of this provider.

## Using this catalogue

Name a region of this catalogue as a target of the [Landing Zone Catalog Assessment](/assessment/landing-zone), on the command line or in the app `.swao.yml`:

```bash
swao lz catalogue show aws-iso-e
swao assess --type landing-zone-catalog --app <app-id> --lz-cat-targets "aws-iso-e:eu-isoe-west-1"
```

```yaml
assessment:
  landing_zone:
    targets:
      - aws-iso-e:eu-isoe-west-1
```

A geography such as `aws-iso-e:Europe` instead of a region ID resolves to the default region shown in the summary.

To correct or extend the facts for one engagement, copy the catalogue into the workspace with `swao lz catalogue copy aws-iso-e` and edit `wsp/inputs/catalogs/lz-catalogues/aws-iso-e/index.json`; the workspace copy then takes precedence. See [Adapting LZ catalogues](/runbooks/adapting-lz-catalogues).

Catalogue facts are point-in-time and are not legal advice. Check the date and confidence above and review the provider's contracts before you rely on a verdict.
