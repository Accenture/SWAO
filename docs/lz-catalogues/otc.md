# Open Telekom Cloud / T Cloud Public (otc)

This page describes the Landing Zone catalogue `otc` as shipped with SWAO: the provider and its sovereignty model, the regions with their residency and certifications, how the catalogue is refreshed and how to use it as a target.

## Provider and sovereignty model

Open Telekom Cloud, now marketed as T Cloud Public, is the public cloud of T-Systems International GmbH, a Deutsche Telekom subsidiary. The provider ID stays `otc`. The catalogue covers the regions `eu-de` (Germany) and `eu-nl` (Netherlands), each with three availability zones.

Sovereignty model: the operator is an EU entity without a US parent, so no extraterritorial exposure is recorded. Both regions record BSI C5, ISO/IEC 27001 and SOC 2. Offerings of T Cloud Public outside these two regions are not covered by this catalogue.

## Using this catalogue

Name a region of this catalogue as a target of the [Landing Zone Catalog Assessment](/assessment/landing-zone), on the command line or in the app `.swao.yml`:

```bash
swao lz catalogue show otc
swao assess --type landing-zone-catalog --app <app-id> --lz-cat-targets "otc:eu-de"
```

```yaml
assessment:
  landing_zone:
    targets:
      - otc:eu-de
```

A geography such as `otc:Europe` instead of a region ID resolves to the default region shown in the summary.

To correct or extend the facts for one engagement, copy the catalogue into the workspace with `swao lz catalogue copy otc` and edit `wsp/inputs/catalogs/lz-catalogues/otc/index.json`; the workspace copy then takes precedence. See [Adapting LZ catalogues](/runbooks/adapting-lz-catalogues).

Catalogue facts are point-in-time and are not legal advice. Check the date and confidence above and review the provider's contracts before you rely on a verdict.
