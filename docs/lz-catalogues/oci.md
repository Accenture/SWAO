# Oracle Cloud Infrastructure (oci)

This page describes the Landing Zone catalogue `oci` as shipped with SWAO: the provider and its sovereignty model, the regions with their residency and certifications, how the catalogue is refreshed and how to use it as a target.

## Provider and sovereignty model

Oracle Cloud Infrastructure (OCI) is the public cloud of Oracle Corporation, a US company. The catalogue covers two products, distinguished by region ID: standard OCI regions (`eu-frankfurt-1`, `eu-amsterdam-1`, `me-dubai-1`, `me-jeddah-1`), operated by a US entity, and the OCI EU Sovereign Cloud (`eu-frankfurt-2`, `eu-madrid-2`), operated by Oracle legal entities in the EU.

Sovereignty model: the standard regions record US CLOUD Act and FISA Section 702 exposure. The EU Sovereign Cloud regions record an EU-entity operator but still record US CLOUD Act exposure, as the parent company is a US company. A framework that forbids any US extraterritorial exposure therefore blocks both products; compare the regions side by side to see the difference in services.

## Using this catalogue

Name a region of this catalogue as a target of the [Landing Zone Catalog Assessment](/assessment/landing-zone), on the command line or in the app `.swao.yml`:

```bash
swao lz catalogue show oci
swao assess --type landing-zone-catalog --app <app-id> --lz-cat-targets "oci:eu-frankfurt-1"
```

```yaml
assessment:
  landing_zone:
    targets:
      - oci:eu-frankfurt-1
```

A geography such as `oci:Europe` instead of a region ID resolves to the default region shown in the summary.

To correct or extend the facts for one engagement, copy the catalogue into the workspace with `swao lz catalogue copy oci` and edit `wsp/inputs/catalogs/lz-catalogues/oci/index.json`; the workspace copy then takes precedence. See [Adapting LZ catalogues](/runbooks/adapting-lz-catalogues).

Catalogue facts are point-in-time and are not legal advice. Check the date and confidence above and review the provider's contracts before you rely on a verdict.
