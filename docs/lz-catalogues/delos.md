# Delos Cloud (delos)

This page describes the Landing Zone catalogue `delos` as shipped with SWAO: the provider and its sovereignty model, the regions with their residency and certifications, how the catalogue is refreshed and how to use it as a target.

## Provider and sovereignty model

Delos Cloud is a sovereign cloud for the German public sector based on Microsoft technology. It is offered by Delos Cloud GmbH, a subsidiary of SAP, and operated in German data centres together with Arvato Systems. The catalogue has one region, `de`, which spans the geo-redundant German sites.

Sovereignty model: the operator is an EU entity and no extraterritorial exposure is recorded. The platform builds on technology from a US supplier; consider this supplier dependency separately from the jurisdiction facts. Many services are still announced or in preview, no certifications are recorded yet and the confidence is low, so check the service status with the provider before an engagement.

## Certifications

The catalogue records no certifications for any region. A framework that requires a certification (for example BSI C5) therefore reports a certification gap for every region of this provider.

## Using this catalogue

Name a region of this catalogue as a target of the [Landing Zone Catalog Assessment](/assessment/landing-zone), on the command line or in the app `.swao.yml`:

```bash
swao lz catalogue show delos
swao assess --type landing-zone-catalog --app <app-id> --lz-cat-targets "delos:de"
```

```yaml
assessment:
  landing_zone:
    targets:
      - delos:de
```

A geography such as `delos:Europe` instead of a region ID resolves to the default region shown in the summary.

To correct or extend the facts for one engagement, copy the catalogue into the workspace with `swao lz catalogue copy delos` and edit `wsp/inputs/catalogs/lz-catalogues/delos/index.json`; the workspace copy then takes precedence. See [Adapting LZ catalogues](/runbooks/adapting-lz-catalogues).

Catalogue facts are point-in-time and are not legal advice. Check the date and confidence above and review the provider's contracts before you rely on a verdict.
