# Google Cloud Platform (gcp)

This page describes the Landing Zone catalogue `gcp` as shipped with SWAO: the provider and its sovereignty model, the regions with their residency and certifications, how the catalogue is refreshed and how to use it as a target.

## Provider and sovereignty model

Google Cloud Platform is the public cloud of Google LLC, a US company. The catalogue covers 42 regions and is generated from a public region picker product list.

Sovereignty model: every region is operated by a US entity and records US CLOUD Act and FISA Section 702 exposure. Three European regions record a BSI C5 attestation: `europe-west3` (Frankfurt), `europe-west10` (Berlin) and `europe-west4` (Netherlands). Sovereign offerings that partners operate on Google Cloud technology are not part of this catalogue.

## Using this catalogue

Name a region of this catalogue as a target of the [Landing Zone Catalog Assessment](/assessment/landing-zone), on the command line or in the app `.swao.yml`:

```bash
swao lz catalogue show gcp
swao assess --type landing-zone-catalog --app <app-id> --lz-cat-targets "gcp:europe-west3"
```

```yaml
assessment:
  landing_zone:
    targets:
      - gcp:europe-west3
```

A geography such as `gcp:Europe` instead of a region ID resolves to the default region shown in the summary.

To correct or extend the facts for one engagement, copy the catalogue into the workspace with `swao lz catalogue copy gcp` and edit `wsp/inputs/catalogs/lz-catalogues/gcp/index.json`; the workspace copy then takes precedence. See [Adapting LZ catalogues](/runbooks/adapting-lz-catalogues).

Catalogue facts are point-in-time and are not legal advice. Check the date and confidence above and review the provider's contracts before you rely on a verdict.
