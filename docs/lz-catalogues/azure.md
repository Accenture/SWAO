# Microsoft Azure (azure)

This page describes the Landing Zone catalogue `azure` as shipped with SWAO: the provider and its sovereignty model, the regions with their residency and certifications, how the catalogue is refreshed and how to use it as a target.

## Provider and sovereignty model

Microsoft Azure is the public cloud of Microsoft Corporation, a US company. The catalogue covers 87 Azure regions and is generated from the public Azure Retail Prices API. Besides the regular regions it contains a number of edge, staging and partner locations whose residency country is not recorded.

Sovereignty model: every region is operated by a US entity and records US CLOUD Act and FISA Section 702 exposure. `germanywestcentral` is the only region with a recorded BSI C5 attestation. For Microsoft technology operated by a European entity, see the [Delos Cloud](/lz-catalogues/delos) catalogue; for Azure services at the customer's own site, see [Azure Local](/lz-catalogues/azure-local).

## Using this catalogue

Name a region of this catalogue as a target of the [Landing Zone Catalog Assessment](/assessment/landing-zone), on the command line or in the app `.swao.yml`:

```bash
swao lz catalogue show azure
swao assess --type landing-zone-catalog --app <app-id> --lz-cat-targets "azure:germanywestcentral"
```

```yaml
assessment:
  landing_zone:
    targets:
      - azure:germanywestcentral
```

A geography such as `azure:Europe` instead of a region ID resolves to the default region shown in the summary.

To correct or extend the facts for one engagement, copy the catalogue into the workspace with `swao lz catalogue copy azure` and edit `wsp/inputs/catalogs/lz-catalogues/azure/index.json`; the workspace copy then takes precedence. See [Adapting LZ catalogues](/runbooks/adapting-lz-catalogues).

Catalogue facts are point-in-time and are not legal advice. Check the date and confidence above and review the provider's contracts before you rely on a verdict.
