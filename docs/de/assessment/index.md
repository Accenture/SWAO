# Bewertung durchführen

SWAO unterstützt drei Bewertungstypen:

- **Anwendungsbewertung** -- Analyse des Quellcodes auf Compliance, Risiken und Cloud-Readiness
- **Landing-Zone-Bewertung** -- Eignung einer Cloud-Landing-Zone für souveräne Workloads
- **LLM-Bewertung** -- Bewertung von Sprachmodellen auf Datenschutz- und Souveränitätsanforderungen

Wählen Sie einen Bewertungstyp in der Seitenleiste aus, um zu beginnen.
