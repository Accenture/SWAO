# Landing-Zone-Bewertung

Die Landing-Zone-Bewertung prueft, ob eine Cloud-Landing-Zone die Souveraeni­taets­anforderungen Ihrer Anwendung erfuellt.

SWAO liefert vorkonfigurierte Kataloge fuer 12 Anbieter -- darunter STACKIT, OTC (T-Systems), IONOS Cloud, OVHcloud, Microsoft Azure EU, AWS eu-central-1 und weitere. Die Kataloge sind anpassbar.

## Aufruf

```bash
swao assess --type landing-zone --app <app-id>
```

Alternativ: TUI-Option 3 -> Landing-Zone-Bewertung.

## Ausgabe

- Fit/Gap-Bericht je Landing Zone
- Empfehlung der geeignetsten Zielplattform
- HTML-Publikation mit auditfaehiger Nachvollziehbarkeit

Weitere Details zu den verfuegbaren Katalogen finden Sie auf der Seite [Funktionen und Editionen](/de/features).
