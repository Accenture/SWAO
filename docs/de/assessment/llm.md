# LLM-Bewertung

Die LLM-Bewertung (Sprachmodell-Bewertung) prueft KI-Modelle auf:

- Datenschutz- und Souveraeni­taets­anforderungen
- Datenspeicherung und -verarbeitung in der EU
- Einhaltung von BSI C5, DORA und weiteren Rahmenwerken
- Eignung fuer regulierte Branchen (Finanzen, Gesundheit, oeffentlicher Sektor)

## Aufruf

```bash
swao assess --type llm
```

Alternativ: TUI-Option 3 -> LLM-Bewertung.

## Ausgabe

- Vergleichsbericht ueber mehrere LLM-Anbieter
- Compliance-Matrix je Rahmenwerk
- Empfehlung mit Begruendung und Quellnachweisen
