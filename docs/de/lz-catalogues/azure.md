# Microsoft Azure (azure)

Diese Seite beschreibt den Landing-Zone-Katalog `azure`, wie er mit SWAO ausgeliefert wird: den Anbieter und sein Souveränitätsmodell, die Regionen mit Datenresidenz und Zertifizierungen, wie der Katalog aktualisiert wird und wie Sie ihn als Ziel verwenden.

## Anbieter und Souveränitätsmodell

Microsoft Azure ist die Public Cloud der Microsoft Corporation, eines US-Unternehmens. Der Katalog umfasst 87 Azure-Regionen und wird aus der öffentlichen Azure Retail Prices API erzeugt. Neben den regulären Regionen enthält er einige Edge-, Staging- und Partnerstandorte, deren Residenzland nicht erfasst ist.

Souveränitätsmodell: Jede Region wird von einem Unternehmen in den USA betrieben und erfasst Zugriffsrechte nach US CLOUD Act und FISA Section 702. `germanywestcentral` ist die einzige Region mit erfasstem BSI-C5-Testat. Für Microsoft-Technologie unter einem europäischen Betreiber siehe den Katalog [Delos Cloud](/de/lz-catalogues/delos); für Azure-Dienste am eigenen Standort des Kunden siehe [Azure Local](/de/lz-catalogues/azure-local).

## Diesen Katalog verwenden

Geben Sie eine Region dieses Katalogs als Ziel der [Landing-Zone-Katalog-Bewertung](/de/assessment/landing-zone) an, auf der Kommandozeile oder in der `.swao.yml` der App:

```bash
swao lz catalogue show azure
swao assess --type landing-zone-catalog --app <app-id> --lz-cat-targets "azure:germanywestcentral"
```

```yaml
assessment:
  landing_zone:
    targets:
      - azure:germanywestcentral
```

Eine Geografie wie `azure:Europe` anstelle einer Regions-ID wird zur Standardregion aus dem Überblick aufgelöst.

Um die Fakten für ein Engagement zu korrigieren oder zu ergänzen, kopieren Sie den Katalog mit `swao lz catalogue copy azure` in den Workspace und bearbeiten `wsp/inputs/catalogs/lz-catalogues/azure/index.json`; die Workspace-Kopie hat dann Vorrang. Siehe [Landing-Zone-Kataloge anpassen](/de/runbooks/adapting-lz-catalogues).

Katalogfakten geben einen Stand zu einem Zeitpunkt wieder und sind keine Rechtsberatung. Prüfen Sie Datum und Konfidenz oben sowie die Verträge des Anbieters, bevor Sie sich auf ein Ergebnis stützen.
