# Amazon Web Services (aws)

Diese Seite beschreibt den Landing-Zone-Katalog `aws`, wie er mit SWAO ausgeliefert wird: den Anbieter und sein Souveränitätsmodell, die Regionen mit Datenresidenz und Zertifizierungen, wie der Katalog aktualisiert wird und wie Sie ihn als Ziel verwenden.

## Anbieter und Souveränitätsmodell

Amazon Web Services (AWS) ist die Public Cloud der Amazon Web Services, Inc., eines US-Unternehmens. Der Katalog umfasst die 34 kommerziellen AWS-Regionen weltweit und wird aus den Endpunktdaten des AWS SDK erzeugt.

Souveränitätsmodell: Jede Region wird von einem Unternehmen in den USA betrieben, daher sind der US CLOUD Act und FISA Section 702 als extraterritoriale Zugriffsrechte erfasst, unabhängig davon, wo die Daten liegen. Rahmenwerke, die diese Zugriffsrechte ausschließen (zum Beispiel BSI C5), blockieren deshalb jede AWS-Region; Rahmenwerke ohne solche Anforderungen prüfen nur die Verfügbarkeit der Dienste. In SWAO ist der Katalog der Bezugspunkt für Hyperscaler; ein Vergleich mit `aws-esc` zeigt, was die AWS European Sovereign Cloud bietet.

## Diesen Katalog verwenden

Geben Sie eine Region dieses Katalogs als Ziel der [Landing-Zone-Katalog-Bewertung](/de/assessment/landing-zone) an, auf der Kommandozeile oder in der `.swao.yml` der App:

```bash
swao lz catalogue show aws
swao assess --type landing-zone-catalog --app <app-id> --lz-cat-targets "aws:eu-central-1"
```

```yaml
assessment:
  landing_zone:
    targets:
      - aws:eu-central-1
```

Eine Geografie wie `aws:Europe` anstelle einer Regions-ID wird zur Standardregion aus dem Überblick aufgelöst.

Um die Fakten für ein Engagement zu korrigieren oder zu ergänzen, kopieren Sie den Katalog mit `swao lz catalogue copy aws` in den Workspace und bearbeiten `wsp/inputs/catalogs/lz-catalogues/aws/index.json`; die Workspace-Kopie hat dann Vorrang. Siehe [Landing-Zone-Kataloge anpassen](/de/runbooks/adapting-lz-catalogues).

Katalogfakten geben einen Stand zu einem Zeitpunkt wieder und sind keine Rechtsberatung. Prüfen Sie Datum und Konfidenz oben sowie die Verträge des Anbieters, bevor Sie sich auf ein Ergebnis stützen.
