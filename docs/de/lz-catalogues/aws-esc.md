# AWS European Sovereign Cloud (aws-esc)

Diese Seite beschreibt den Landing-Zone-Katalog `aws-esc`, wie er mit SWAO ausgeliefert wird: den Anbieter und sein Souveränitätsmodell, die Regionen mit Datenresidenz und Zertifizierungen, wie der Katalog aktualisiert wird und wie Sie ihn als Ziel verwenden.

## Anbieter und Souveränitätsmodell

Die AWS European Sovereign Cloud ist eine eigene AWS-Partition in der EU, die von in der EU ansässigen AWS-Gesellschaften unabhängig von den globalen AWS-Regionen betrieben wird. Der Katalog enthält ihre Region `eusc-de-east-1` in Deutschland und wird aus denselben Endpunktdaten des AWS SDK erzeugt wie `aws`, sodass sich die Dienstliste direkt mit AWS Frankfurt (`eu-central-1`) vergleichen lässt.

Souveränitätsmodell: Der Katalog erfasst einen Betreiber mit Sitz in der EU, keine extraterritorialen Zugriffsrechte und die Zertifizierungen BSI C5 und ISO/IEC 27001. Ein Rahmenwerk wie BSI C5 kann mit dieser Region daher erfüllt werden, sofern die benötigten Dienste verfügbar sind.

## Diesen Katalog verwenden

Geben Sie eine Region dieses Katalogs als Ziel der [Landing-Zone-Katalog-Bewertung](/de/assessment/landing-zone) an, auf der Kommandozeile oder in der `.swao.yml` der App:

```bash
swao lz catalogue show aws-esc
swao assess --type landing-zone-catalog --app <app-id> --lz-cat-targets "aws-esc:eusc-de-east-1"
```

```yaml
assessment:
  landing_zone:
    targets:
      - aws-esc:eusc-de-east-1
```

Eine Geografie wie `aws-esc:Europe` anstelle einer Regions-ID wird zur Standardregion aus dem Überblick aufgelöst.

Um die Fakten für ein Engagement zu korrigieren oder zu ergänzen, kopieren Sie den Katalog mit `swao lz catalogue copy aws-esc` in den Workspace und bearbeiten `wsp/inputs/catalogs/lz-catalogues/aws-esc/index.json`; die Workspace-Kopie hat dann Vorrang. Siehe [Landing-Zone-Kataloge anpassen](/de/runbooks/adapting-lz-catalogues).

Katalogfakten geben einen Stand zu einem Zeitpunkt wieder und sind keine Rechtsberatung. Prüfen Sie Datum und Konfidenz oben sowie die Verträge des Anbieters, bevor Sie sich auf ein Ergebnis stützen.
