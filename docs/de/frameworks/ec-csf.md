# EC Cloud Sovereignty Framework (CSF)

> **Diese Seite ist noch nicht auf Deutsch verfügbar.**

**Framework-ID:** `EC_CSF` | **Behoerde:** Europäische Kommission

Das EC Cloud Sovereignty Framework definiert Anforderungen an die digitale Souveränität fuer Cloud-Dienste im europäischen oeffentlichen Sektor.
