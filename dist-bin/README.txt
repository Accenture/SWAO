SWAO Pre-built Binaries
=======================

This directory contains the pre-built SWAO binaries for all supported platforms.
Binaries are published as GitHub Release assets and are not tracked in git.

Three editions are available for each platform -- choose the one that matches
your licence:

  Windows (x64)
    swao-community-win-x64.exe    Community Edition (Apache-2.0, no licence key)
    swao-consultant-win-x64.exe   Consultant Edition (licence key required)
    swao-enterprise-win-x64.exe   Enterprise Edition (licence key required)

  Linux (x64)
    swao-community-linux-x64      Community Edition (Apache-2.0, no licence key)
    swao-consultant-linux-x64     Consultant Edition (licence key required)
    swao-enterprise-linux-x64     Enterprise Edition (licence key required)

  macOS Intel (x64)
    swao-community-macos-x64      Community Edition (Apache-2.0, no licence key)
    swao-consultant-macos-x64     Consultant Edition (licence key required)
    swao-enterprise-macos-x64     Enterprise Edition (licence key required)

  macOS Apple Silicon (arm64)
    swao-community-macos-arm64    Community Edition (Apache-2.0, no licence key)
    swao-consultant-macos-arm64   Consultant Edition (licence key required)
    swao-enterprise-macos-arm64   Enterprise Edition (licence key required)

SHA256 checksums for all binaries are in SHA256SUMS.

See https://github.com/Accenture/SWAO/releases for the latest release.
See docs/runbooks/install.md for platform-specific installation instructions.
