SWAO Pre-built Binaries
=======================

This directory contains the pre-built SWAO binaries for all supported platforms.
Binaries are published as GitHub Release assets and are not tracked in git.

After downloading a release, place the binary for your platform here and run it directly:

  swao-win-x64.exe     Windows (x64)
  swao-linux-x64       Linux (x64)
  swao-darwin-x64      macOS (Intel)
  swao-darwin-arm64    macOS (Apple Silicon)

SHA256 checksums for all binaries are in SHA256SUMS.

See https://github.com/Accenture/SWAO/releases for the latest release.
See docs/runbooks/install.md for platform-specific installation instructions.
