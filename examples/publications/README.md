# Sample SWAO Publications

Three HTML publications generated by SWAO from the Sovereign Health reference
workspace, showing all three assessment types and the Engagement Hub.

## Files

| File | Assessment type | Open |
|---|---|---|
| `latest-application.html` | Application Assessment | Entry point -- redirects to the timestamped file below |
| `2026-08-23T17-29-27-sovereign-health.html` | Application Assessment | Full 14-pass assessment of Sovereign Health |
| `latest-lz.html` | Landing Zone Assessment | Entry point -- redirects to the timestamped file below |
| `2026-08-24T11-36-12-sovereign-health-lz.html` | Landing Zone Assessment | LZ readiness check for the Sovereign Health workspace |
| `latest-llm.html` | LLM Assessment | Entry point -- redirects to the timestamped file below |
| `2026-08-24-08-32-09-llm-assessment.html` | LLM Assessment | LLM provider benchmark results |
| `engagement-hub.html` | Portfolio / Engagement Hub | Multi-app portfolio summary (HTML Portal, Enterprise) |

## How to view

Open any file directly in a browser -- the publications are fully self-contained
single-page HTML files with no external dependencies. The `latest-*.html` files
are convenience redirects; open them or the timestamped file directly.

## How these were generated

Run these commands from the root of a SWAO portfolio workspace. The Sovereign
Health reference workspace is maintained in the private development repository
and is not included in this public repo.

```bash
swao assess --app sovereign-health
swao publish --app sovereign-health

swao assess --app sovereign-health --passes landing-zone
swao publish --app sovereign-health --type lz

swao assess --app sovereign-health --passes llm-assessment
swao publish --app sovereign-health --type llm
```

## Regenerating

Run the commands above against your own workspace. The output lands in
`wsp/outputs/` and is published to `wsp/outputs/published/`. Copy the HTML
files here to update the samples.
