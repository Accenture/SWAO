# Verification of Audit Finding Remediation (DER.3.1.A3) -- evidence template

## Purpose

All audit findings must undergo independent follow-up verification confirming remediation was completed within agreed timeframes; outstanding findings must be escalated to management.

## Evidence required

- Follow-up verification records for findings from the most recent audit, showing each finding, agreed remediation, and verified-closed status
- Evidence that the verifier is independent of the team that performed remediation, confirmed by organisational separation or a named independent reviewer
- Management escalation records for any findings that were overdue, showing escalation was triggered and a response received
- Updated remediation register showing verified-closed items with verification date and verifier name
- Confirmation that verification is built into the standard audit lifecycle process, evidenced by procedure documentation or audit methodology description
