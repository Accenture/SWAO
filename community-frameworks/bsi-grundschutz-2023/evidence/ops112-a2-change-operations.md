# Maintaining Operations During Changes (OPS.1.1.2.A2) -- evidence template

## Purpose

Changes must be planned to minimise disruption to operations, deployed in defined maintenance windows where possible, and must have rollback plans defined and tested before deployment.

## Evidence required

- Maintenance window policy or schedule showing defined windows for significant changes
- Rollback plan for at least one recent significant change, including tested rollback procedure
- Evidence that significant changes were rehearsed in a non-production environment before production deployment
- Post-change review records completed within 48 hours for a sample of recent significant deployments
- Change record showing maintenance window compliance for a recent deployment
