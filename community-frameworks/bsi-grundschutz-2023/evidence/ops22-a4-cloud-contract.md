# Cloud Service Agreement and Data Processing Contract (OPS.2.2.A4) -- evidence template

## Purpose

A written agreement must be in place with each cloud service provider covering security obligations, data processing terms, incident reporting, audit rights, and exit provisions, reviewed before each contract renewal.

## Evidence required

- Data processing agreement (DPA) in place with each provider processing personal data, with signed copies available
- DPA checklist confirming all mandatory clauses are present, including security obligations, incident reporting timelines, audit rights, and exit provisions
- Compliance confirmation for applicable data protection law within the DPA terms, such as a legal review sign-off or GDPR adequacy note
- Contract renewal date tracker for cloud provider agreements, confirming review occurs before expiry
- Evidence of DPA review at the most recent contract renewal, with any updated clauses noted
