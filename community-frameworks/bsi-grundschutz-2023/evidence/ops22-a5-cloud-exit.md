# Cloud Service Exit Planning (OPS.2.2.A5) -- evidence template

## Purpose

A documented exit plan must define the procedures, timelines, and steps to migrate away from each critical cloud service, covering data portability and continuity during transition.

## Evidence required

- Exit plan document for each critical cloud service, covering migration procedures, estimated timelines, and responsible parties
- Data portability test evidence showing a successful export and reimport of representative data from the cloud service
- Contract clauses covering exit provisions and data return timelines, confirming the provider is contractually obligated to support exit
- Most recent annual review date of each exit plan, confirming plans are kept current
- Evidence that the exit plan is reviewed at contract renewal, with a reviewer sign-off or meeting record on file
