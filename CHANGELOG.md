# Changelog

All notable changes to SWAO are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)
and SWAO adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- 11 community compliance frameworks exposed at root level (`community-frameworks/`)
  for standalone download and customisation: GDPR, AI 10 Pillars, BSI C5,
  BSI IT-Grundschutz 2023, HIPAA/NIST SP 800-66r2, LLM Selection, NCA CCC 2024
  CSP/CST, NCA ECC 2024, PCI-DSS v4, SAMA CSF v1.
- Structured GitHub Issue forms replacing legacy Markdown templates (bug report,
  feature request, community framework, provider driver).
- CODEOWNERS file assigning default review to the swao-maintainers team.
- Dependabot weekly update schedule for GitHub Actions.
- CodeQL default-setup scanning on push and pull request.
- Community binary re-attachment workflow (`release-community.yml`).
