# @swao/community

**Tier:** Community

The three compliance frameworks bundled with the Community Edition: GDPR (EU General Data Protection Regulation), AI 10 Pillars (Accenture Responsible AI), and NIST SP 800-66R2 (HIPAA Security Rule guidance). All frameworks are Apache-2.0 open source.

## Install

```bash
pnpm add @swao/community-frameworks
```

## Key API

- `getFrameworkRegistry() -- returns all bundled framework entries`
- `frameworks/gdpr/ -- GDPR lenses and controls`
- `frameworks/ai-10-pillars/ -- AI Responsible Use lenses`
- `frameworks/nist-sp-800-66r2/ -- NIST HIPAA guidance lenses`
