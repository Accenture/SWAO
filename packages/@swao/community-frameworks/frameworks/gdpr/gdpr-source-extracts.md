A reviewer fact-checks the catalogue by comparing each control description against the corresponding extract here.

**Method:** Text extracted via `pypdf` from the source PDF; the EUR-Lex PDF inserts spurious intra-word spacing as a kerning artefact (e.g. `Ar ticle`, `data` rendered as `da ta`); the extract below applies a normalisation pass to fix the most common artefacts. Where extraction artefacts remain visible, the source PDF is the authoritative reference.

**Fact-check loop:** for each control, open the corresponding article extract below, and compare against the control description in `controls.yaml`. If the description departs from the extract, the catalogue is the bug.
