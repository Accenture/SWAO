# Information Security Roles and Responsibilities Defined (OIS-02) -- consultant-furnished context

## Verdict (consultant-asserted)

outcome: PARTIAL
severity: high
rationale: >-
  A CISO has been appointed and the role is documented in the organisational
  chart. However, there is no published RACI matrix covering information
  security responsibilities across the cloud service delivery teams.
  Subcontractors involved in infrastructure operations have no defined
  security accountability mapped to the service provider. This partially
  satisfies OIS-02; the completeness of coverage across the full delivery
  chain and formal publication are outstanding.

## Roles and responsibilities register

| Requirement | Current state | Gap |
| --- | --- | --- |
| Responsible person or function named | CISO appointed and documented | No gap |
| Roles defined for all relevant staff | Defined for internal IT only | Yes |
| Responsibilities documented | Partial (job descriptions only) | Yes |
| Communicated to all relevant staff | Not formally communicated | Yes |
| Subcontractor accountability defined | Not addressed | Yes |
| Incident and continuity responsibilities covered | Not covered | Yes |

## Counter-hypothesis considered

Considered whether job description references to security obligations satisfy
the OIS-02 requirement to define and communicate roles. Rejected: job
descriptions are per-person and do not constitute a systemic RACI covering
the cloud service. The criterion requires documented roles across the
operational context, not individual job-level references.
