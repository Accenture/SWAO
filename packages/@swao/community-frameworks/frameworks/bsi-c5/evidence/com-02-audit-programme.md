# Internal Audit Programme Covering C5 Criteria (COM-02) -- consultant-furnished context

## Verdict (consultant-asserted)

outcome: NOT_MET
severity: medium
rationale: >-
  No internal audit programme exists that covers the C5 criteria. An
  external pen test was conducted 14 months ago but it covered only
  technical attack surface, not the full C5 Basic Criteria set. There
  is no internal audit function and no audit schedule. Management does
  not receive periodic audit findings. The control is not met; an audit
  programme covering C5 criteria must be defined and scheduled.

## Counter-hypothesis considered

Considered whether the external pen test satisfies the internal audit
requirement. Rejected: a pen test is a technical assessment of attack
surface, not an audit of the organisational and procedural C5 criteria.
COM-02 requires periodic assessment against the full C5 control set,
including organisational, personnel, physical, and compliance domains
that are outside the scope of a technical pen test.
