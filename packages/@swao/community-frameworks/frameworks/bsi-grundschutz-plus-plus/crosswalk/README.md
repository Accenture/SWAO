## How the crosswalk is used in controls.yaml

- `maps_to` lists SWAO BSI_GRUNDSCHUTZ_2023 control ids and SWAO ISO_27001 control ids that the BSI files map to the GS++ requirement (any relationship), restricted to ids that exist in the bundled SWAO frameworks.
- `evidence_basis` always starts with the Praktik evidence document; automated `signal_prefix` evidence of a 2023 control is inherited only for `equal-to`, `equivalent-to` or 2023 `superset-of` GS++.
- Relationship types and the full 2023 scope (all Bausteine, not only the 105 SWAO controls) are only in the CSVs.
