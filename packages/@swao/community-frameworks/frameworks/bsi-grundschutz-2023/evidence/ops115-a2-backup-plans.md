# Backup Failure Response Plans (OPS.1.1.5.A2) -- evidence template

## Purpose

Documented plans must define the response to backup failures, including escalation path and contingency measures to minimise data loss until backup capability is restored.

## Evidence required

- Backup failure response procedure document defining detection, notification, and remediation steps for backup failures
- Escalation path for backup failures, specifying the recipient and maximum response timeframe for each escalation tier
- Contingency measures defined for each backup tier in scope, covering the period until backup capability is restored
- Evidence that the backup failure response procedure is included in the operations runbook and accessible to on-call staff
- Evidence that the failure response plan was exercised as part of the annual BCP test, with test results on file
