# Security Requirements for Cloud Service Providers (OPS.2.2.A3) -- evidence template

## Purpose

Minimum security requirements for cloud service providers handling organisational data must be defined, covering certifications (BSI C5, ISO 27001, or SOC 2 Type II), data residency, subprocessor transparency, audit rights, and incident notification obligations.

## Evidence required

- Defined minimum certification bar for cloud providers processing personal data, documented in a supplier security policy or procurement standard
- Evidence of certification compliance for at least one major provider, such as a current BSI C5 attestation, ISO 27001 certificate, or SOC 2 Type II report
- Subprocessor register or transparency report from a key provider, showing disclosure of fourth-party data processors
- Evidence that requirements are verified before onboarding, such as a completed due diligence checklist for a recent new provider
- Annual reassessment records for key providers, confirming continued compliance with the defined requirements
