# Management Responsibility for Information Security (ISMS.1.A1) -- consultant-furnished context

## Verdict (consultant-asserted)

outcome: PARTIAL
severity: high
rationale: >-
  Senior management has verbally committed to the information security
  programme and nominally sponsors it. However, the commitment has not been
  formalised: no written management endorsement of the security programme
  exists, the information security process has not been reviewed or re-approved
  since its initial rollout, and information security is not a standing agenda
  item in management reporting. The information security officer operates with
  delegated authority from the CTO but the delegation is informal. This
  satisfies the spirit of ISMS.1.A1 partially; the documentation and governance
  formality required by the Basis requirement are not yet in place.

## Management commitment register

| Requirement | Current state | Gap |
| --- | --- | --- |
| Written management endorsement of security programme | Not documented | Yes |
| Annual management review of information security posture | Not scheduled | Yes |
| Information security in management reporting cycle | Ad hoc only | Yes |
| Adequate resources allocated for information security | Informal budget line | Partial |
| Active support for the information security officer | Present (verbal) | No gap |

## Counter-hypothesis considered

Considered whether the CTO's verbal commitment and day-to-day involvement
constitutes sufficient management responsibility under ISMS.1.A1. Rejected:
the BSI requirement explicitly calls for a documented and actively maintained
information security process with management approval -- verbal commitment
does not satisfy the Basis requirement.
