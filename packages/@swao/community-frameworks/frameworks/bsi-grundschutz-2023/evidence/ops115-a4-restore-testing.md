# Restore Testing and Documentation (OPS.1.1.5.A4) -- evidence template

## Purpose

Recovery procedures must be tested at regular intervals to verify that data can be restored within the agreed RTO; test results must document time taken and data completeness, with failures tracked and remediated before the next test cycle.

## Evidence required

- Restore test records covering the last four quarters, with dates, scope, and outcomes
- Documented RTO target and measured actual restore time from the most recent test, showing target was met or gap is tracked
- Data completeness log from the most recent test confirming all expected data was recovered without corruption
- Records of any failures from previous tests and their remediation status, including re-test evidence where failures occurred
- Confirmation that tests cover all backup tiers, including application data, configuration, and database backups
