# Incident Classification and Prioritisation (DER.2.1.A2) -- evidence template

## Purpose

Security incidents must be classified and prioritised according to documented criteria covering impact, urgency, and scope; personal data breaches must be identified as a distinct incident class triggering data protection notification obligations.

## Evidence required

- Severity matrix with classification criteria and escalation thresholds, showing how impact, urgency, and scope are combined to determine priority
- Evidence that the matrix is used operationally, such as sample incident records showing classification fields populated
- Documented definition of a personal data breach as a distinct incident class, with reference to the associated notification obligations and timelines
- Evidence that first responders are trained on breach identification criteria, such as training records or a completed briefing acknowledgement
- SIEM or detection tool configuration showing breach-related alert rules or triage categories aligned to the classification scheme
