# Backup Media Rotation and Off-site Storage (CON.3.A5) -- evidence template

## Purpose

A rotation scheme must be defined for tape or removable backup media; at least one copy must be stored off-site at all times; the off-site location must meet equivalent physical security standards.

## Evidence required

- Documented rotation schedule for backup media, covering all media types in scope and the rotation cadence
- Confirmation that at least one current off-site backup copy exists, evidenced by an inventory record or cloud storage manifest
- Physical security assessment or written description of the off-site location, confirming it meets equivalent security standards
- Evidence of a successful off-site retrieval test conducted at least annually, with test date and outcome recorded
- Confirmation that the off-site location is geographically separated from the primary site, with the separation distance or region documented
