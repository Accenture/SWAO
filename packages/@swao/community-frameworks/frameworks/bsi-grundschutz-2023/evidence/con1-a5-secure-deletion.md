# Secure Deletion and Destruction of Data (CON.1.A5) -- evidence template

## Purpose

Data no longer required must be securely deleted or physically destroyed using a method appropriate to the data classification; simple file deletion is insufficient for confidential data; all deletions must be documented.

## Evidence required

- Secure deletion policy specifying the required deletion method per data classification, including minimum standards for confidential and restricted data
- Deletion log for sensitive data assets showing the deletion method, data classification, date, and authorising person for each deletion event
- Evidence that storage media is overwritten or cryptographically erased before disposal, such as a media disposal certificate
- Records confirming that backup copies are included in the deletion scope and are addressed before media disposal
- Confirmation that the deletion procedure is tested periodically, with test results and date on file
