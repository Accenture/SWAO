# Backup Concept (CON.3.A2) -- evidence template

## Purpose

A backup concept must define scope, frequency, retention periods, storage media, and off-site or out-of-region placement for all backups, including configuration data, aligned to agreed RPO objectives.

## Evidence required

- Approved backup concept document covering all in-scope systems, backup types, frequency, and retention periods
- Evidence that all in-scope systems are listed in the concept (databases, object storage, application configuration)
- Confirmation of off-site or out-of-region placement for at least one backup copy, including the target location
- Backup schedule and retention schedule per system, showing alignment with documented RPO values
- Review date and approver signature on the concept, confirming it is current and formally accepted
