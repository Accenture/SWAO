# Information Security Requirements for Software Procurement (CON.6.A1) -- evidence template

## Purpose

Information security requirements covering authentication, access control, audit logging, cryptographic capabilities, and data residency must be defined before procuring software or cloud services, included as contractual criteria, and verified before contract signature.

## Evidence required

- Security requirements checklist used in procurement, covering authentication, access control, audit logging, cryptography, and data residency
- Example request-for-proposal or evaluation criteria including security requirements, demonstrating requirements are part of the selection process
- Evidence that security requirements are reflected in at least one recent contract or service agreement (redacted where necessary)
- Confirmation that requirements were verified before go-live, such as a pre-acceptance security sign-off record
- Named owner responsible for the procurement security check process, with documented accountability
