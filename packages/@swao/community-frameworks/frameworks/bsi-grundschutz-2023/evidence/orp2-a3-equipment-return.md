# Secure Return of Equipment and Credentials on Departure (ORP.2.A3) -- evidence template

## Purpose

All institutional equipment, credentials, access cards, and keys must be formally returned by departing staff before or at departure; return must be documented and confirmed by an authorised person.

## Evidence required

- Equipment and credential return checklist as part of the offboarding procedure, covering all equipment types (laptops, tokens, access cards, keys, certificates)
- Manager confirmation of completed return for a sample of recent leavers, signed or recorded in the HR or IT system
- Documented escalation of any outstanding returns to the ISO within 24 hours, showing the escalation path is defined and used
- Evidence that the return checklist covers all required equipment categories without omission
- Record of at least one case where an outstanding return was escalated and subsequently resolved within the defined timeframe
