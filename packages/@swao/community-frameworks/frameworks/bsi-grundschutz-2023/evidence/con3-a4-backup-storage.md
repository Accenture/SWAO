# Physical and Logical Protection of Backup Media (CON.3.A4) -- evidence template

## Purpose

Backup media must be stored in a physically secured location with access controlled and logged; logical access to backup repositories must be restricted to authorised personnel only.

## Evidence required

- Physical access control records for backup media storage, such as an access log or key register, confirming access events are captured
- List of authorised personnel with access to backup media or repositories, current as of the most recent access review
- Logical access control configuration for backup repositories, confirming role-based restrictions are in place
- MFA or equivalent protection for remote backup repository access, evidenced by configuration screenshots or policy confirmation
- Most recent access review record confirming the authorised list was verified and is current
