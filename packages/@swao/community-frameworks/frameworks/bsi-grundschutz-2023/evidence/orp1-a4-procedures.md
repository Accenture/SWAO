# Documented Operating Procedures (ORP.1.A4) -- evidence template

## Purpose

Documented operating procedures must exist for all security-relevant processes including onboarding, offboarding, change management, incident response, and backup and recovery; each procedure must have an owner and a defined review cycle.

## Evidence required

- Procedure inventory listing all documented security-relevant processes with document titles, version numbers, and storage locations
- Named procedure owners for each document, confirmed in the document itself or in the inventory register
- Evidence that procedures are accessible to all staff responsible for executing them, such as an intranet link, distribution record, or access confirmation
- Last review date for each procedure, with evidence that procedures have been reviewed within their defined review cycle
- Confirmation that procedures exist for all mandatory areas: onboarding, offboarding, change management, incident response, and backup and recovery
