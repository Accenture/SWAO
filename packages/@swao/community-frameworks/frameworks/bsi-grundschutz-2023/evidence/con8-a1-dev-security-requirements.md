# Defining Security Requirements for Software Development (CON.8.A1) -- evidence template

## Purpose

Information security requirements must be defined and integrated into the software development lifecycle from the requirements phase, covering authentication, authorisation, session management, input validation, error handling, and cryptographic protection.

## Evidence required

- Published secure development standard or guidelines (OWASP ASVS or equivalent) adopted by the development organisation
- Evidence that security requirements are captured in development stories or design documents, such as a sample story or design artefact showing security acceptance criteria
- Security review gate records at requirements or design phases, confirming that security requirements were reviewed before development started
- Evidence that developers are aware of and applying the standard, such as training records, onboarding documentation, or acknowledgement logs
- Mapping between the secure development standard and OWASP ASVS or an equivalent baseline, demonstrating coverage of key security requirement categories
