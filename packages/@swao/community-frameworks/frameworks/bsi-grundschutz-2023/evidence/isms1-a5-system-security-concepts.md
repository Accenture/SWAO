# System-Specific Security Concepts for IT Systems (ISMS.1.A5) -- evidence template

## Purpose

Each IT system or group of comparable systems must have a system-specific security concept documenting protection requirements, applicable Bausteine, implemented measures, and approved deviations.

## Evidence required

- System-specific security concept document for each major IT system, covering protection requirements, applicable Bausteine, and implemented measures
- IT-Grundschutz modelling records mapping each system to its assigned Bausteine
- List of approved deviations with risk acceptance sign-off from an authorised approver
- Most recent review date per concept, confirming currency within the defined review cycle
- Evidence that at least one concept was updated following a significant system change in the past review period
