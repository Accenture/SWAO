# Defining Security Measures (ISMS.1.A6) -- evidence template

## Purpose

Security measures necessary to protect information assets must be identified, documented, implemented, and tracked with owners and target dates in a remediation register aligned with the applicable IT-Grundschutz Bausteine.

## Evidence required

- IT-Grundschutz modelling document covering all target objects in scope, with each object mapped to the applicable Bausteine
- Remediation register listing all open measures with assigned owners and target completion dates
- Evidence that measure selection follows the requirements of the relevant Bausteine rather than being defined ad hoc
- Record of the last register review including the review date and the identity of the reviewer
- Sign-off or approval record from the information security officer confirming acceptance of the current measure set and remediation schedule
