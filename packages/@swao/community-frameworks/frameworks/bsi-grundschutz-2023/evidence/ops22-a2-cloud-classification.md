# Classification of Cloud Service Criticality (OPS.2.2.A2) -- evidence template

## Purpose

Cloud services used by the institution must be classified according to criticality and the sensitivity of data they process, driving appropriate levels of security controls, due diligence, and contractual obligations.

## Evidence required

- Cloud service inventory listing all services in use, with owner and data sensitivity noted for each
- Criticality classification assigned to each service, using a defined classification scheme with documented criteria
- Evidence that classification drives different security requirements for high-criticality services, such as tiered control sets or approval thresholds
- Most recent review date of the inventory, confirming it is kept current
- Evidence that the classification is updated when new services are added or existing services change their data-processing scope
