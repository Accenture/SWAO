# Physical Environment Protection for Server Hardware (SYS.1.1.A5) -- evidence template

## Purpose

Server hardware must be protected against overheating, humidity, and power fluctuations; environmental monitoring with automated alerts must be in place; UPS must be installed for availability-critical servers.

## Evidence required

- Environmental monitoring configuration showing temperature and humidity thresholds and the alert recipient list for each monitored zone
- UPS inventory and coverage documentation listing all critical servers and confirming UPS protection is in place for each
- Most recent UPS failover test record, including test date, tested servers, and pass or fail outcome
- Environmental alert history for the past six months, or a signed confirmation that no threshold breaches occurred during that period
- Confirmation that environmental controls are reviewed after any data centre infrastructure change, evidenced by a review record or change management process description
