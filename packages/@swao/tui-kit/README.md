# @swao/tui

**Tier:** Community

Shared Ink (React-for-CLIs) components used across SWAO TUI screens. Provides reusable boxes, progress bars, status badges, and layout primitives.

## Install

```bash
pnpm add @swao/tui-kit
```

## Key API

- `StatusBadge -- coloured pass/fail/warn badge`
- `ProgressBar -- animated progress indicator`
- `SectionBox -- bordered content panel`
- `KeyHint -- keyboard shortcut hint`
